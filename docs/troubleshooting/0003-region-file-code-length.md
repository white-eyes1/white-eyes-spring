# 0003. 경계 파일의 지역 코드 자릿수 가정이 실제 파일과 달랐다(7자리 → 8자리)

- 기록: 2026-10-20
- 관련: 이슈 #7, PR #100, FNC-C-001
- 상태: 해결

## 증상
리뷰에서 실제 경계 파일(admdongkor)은 `adm_cd`가 8자리이고 읍·면·동 다각형만 들어 있다는 지적을 받았다.
구현은 시·도, 시·군·구, 읍·면·동이 모두 파일에 있다고 보고 만들어져 있었다.

## 원인
명세에 파일 형식이 없어 통계청 SGIS 기준(2/5/7자리)으로 가정하고 구현했다. 실제 샘플 파일을 확인하지 않았다.

## 해결
결정 0014에 맞춰 바꿨다.
- 코드는 8자리로 검증한다.
- 읍·면·동의 앞 2자리·5자리로 시·도와 시·군·구 행을 만들고, JTS union으로 경계를 합친다.
- `RegionLevel`을 SIDO/SIGUNGU/EMD로 바꾸고 좌표 범위 검사를 추가했다.
- 실제 파일의 3개 지역(43개 읍·면·동)을 적재해 확인했다(H2 기준 48건, 재실행해도 48건).

## 재발 방지
명세에 없는 입력 형식은 가정하기 전에 실제 샘플 파일을 먼저 받아 확인한다.
