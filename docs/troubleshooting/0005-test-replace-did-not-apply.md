# 0005. 문자열 치환으로 만든 오류 입력이 치환되지 않아 테스트가 실패

- 기록: 2026-10-20
- 관련: 이슈 #7, PR #100
- 상태: 해결

## 증상
시·군·구 이름 충돌 테스트가 `저장된 행이 0건이어야 하는데 6건`으로 실패했다.

## 원인
테스트가 오류 파일을 만들려고 한 줄짜리 문자열을 치환했는데, 실제 파일은 여러 줄이라 치환이 일어나지 않았다.
오류 입력이 아닌 정상 파일이 그대로 적재됐다.

## 해결
한 줄 안에서 일치하는 속성 부분(삼청동 + sidonm + sggnm)만 치환하도록 고쳤다.

## 재발 방지
파일 문자열 치환으로 오류 입력을 만드는 테스트는 치환이 실제로 일어났는지(결과가 원본과 다른지) 먼저 확인한다.
