# 0013. 스택 브랜치를 반복문으로 병합하다 충돌 표시가 커밋됨

- 기록: 2026-10-20
- 관련: 이슈 #10~#14
- 상태: 해결

## 증상
패키지 이동(0012)을 #11~#14에 전파하려고 반복문으로 병합했더니 `ZoneService`, `ZoneRepository`, `CameraController` 등에 충돌 표시(`<<<<<<<`)가 남은 채 커밋됐다. 빌드가 실패했다.

```
error: class, interface, enum, or record expected
```

## 원인
충돌이 나도 `git add -A` 후 커밋하는 스크립트였고, 충돌 검사가 `add` 이후라 미해결 상태를 놓쳤다.
파일 이동과 내용 충돌이 겹치면 git이 파일 안에 충돌 표시를 남긴다.

## 해결
push 전에 발견해 원격에는 영향이 없었다. #11~#14 로컬 브랜치를 origin 상태로 되돌리고 한 브랜치씩 다시 병합했다. 충돌 파일은 각 브랜치 버전을 고르고 패키지 이름만 바꿨다. 병합마다 충돌 표시 검사 → 빌드 → 커밋을 했다.

## 재발 방지
병합 자동화는 충돌이 나면 멈춰야 한다. 커밋 전에 `<<<<<<<`·`>>>>>>>`를 검색해 확인하고, 빌드를 통과한 뒤 커밋한다. 스택은 한 번에 돌리지 않고 브랜치마다 확인한다.
