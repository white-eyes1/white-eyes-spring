# 0016. 선행 이슈 #6(작업 기록 저장)이 dev에 없어 "작업 기록" 단계를 구현하지 못함

- 기록: 2026-10-20
- 관련: 이슈 #10·#11·#13·#14, 선행 #6(FNC-C-026), PR #113
- 상태: 우회

## 증상
다음 처리 단계를 구현할 수 없었다.
- FNC-A-014 구역 등록 순서 5 (ZONE_CHANGE)
- FNC-A-018 캠 등록 순서 5 (CAMERA_CHANGE, op: CREATE)
- FNC-A-020 캠 가동 순서 5 (CAMERA_RUN, op: START)
- FNC-A-021 캠 정지 순서 6 (CAMERA_RUN, op: STOP)

FNC-A-021 순서 4·5(마지막 녹화 `ended_at` 채우기, 열린 이상 이벤트 종료)도 구현하지 못했다. recording 엔티티는 팀원 #17(PR #98)에만 있고, 이벤트 테이블·엔티티는 어디에도 없다.

## 원인
#6은 다른 팀원(ho8566z) 담당이고 시작 전이었다. `work_history` 테이블·저장 함수·로그인 정보가 dev에 없었다(이후 PR #113이 열렸으나 병합 전).

## 해결
서비스에 호출 자리를 주석으로 표시하고, 나머지 단계만 구현했다. 각 PR 본문에 미구현으로 명시했다.
#6 병합 후 같은 트랜잭션 안에서 저장한다. #6의 저장 함수는 트랜잭션 없이 부르면 거부하므로, 정지는 상태 기록 단계 안에서 호출한다.
recording·이벤트 단계(FNC-A-021 순서 4·5)는 #17과 이벤트 이슈가 병합된 뒤 연결한다.

## 재발 방지
선행 이슈가 안 끝난 채 시작하는 이슈는 시작 전에 어디까지 구현할지 팀과 정한다.
