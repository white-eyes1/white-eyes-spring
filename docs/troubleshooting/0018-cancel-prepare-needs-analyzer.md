# 0018. 분석 서버가 없어 "준비 중 정지 시 준비 취소"를 끝까지 확인하지 못함

- 기록: 2026-10-20
- 관련: 이슈 #14, PR #116, FNC-A-021, flask #2(FNC-S-002)
- 상태: 우회

## 증상
이슈 완료 기준 "준비 중 정지 시 준비 취소 확인"을 실제 분석 서버로 확인할 수 없었다.

## 원인
준비를 취소하는 쪽은 분석 서버(flask #2, 선행 이슈)이고, 아직 연결할 수 있는 서버가 없다.

## 해결
가짜 분석 서버로 우리 쪽 동작까지만 확인했다. 준비 중(PREPARING, 진행률 40) 캠을 정지하면 분석 서버에 `POST /analyzer/v1/cameras/{id}/stop`(헤더 `X-Internal-Token`)이 가고, 앱은 STOPPED·`progress=0`·`run_requested=0`이 된다. 한계를 PR에 적었다.
flask #2가 병합되면 실제 더미 캠을 준비 중에 정지해 분석 서버가 준비를 멈추는지 확인해야 한다.

## 재발 방지
다른 저장소의 이슈가 선행인 기능은 완료 기준 중 우리 쪽에서 확인 가능한 부분과 불가능한 부분을 나눠 PR에 적는다.
