# 0009. 테스트가 남긴 행 때문에 다른 테스트 19개가 외래키 오류로 실패

- 기록: 2026-10-20
- 관련: 이슈 #10·#11, PR #107·#109
- 상태: 해결

## 증상
캠 등록 테스트(#11)를 추가하자 기존 지역·미리보기 테스트 19개가 `DELETE FROM region`에서 외래키 오류로 실패했다.

## 원인
테스트들이 같은 H2 DB를 공유한다. 끝난 테스트가 `zone`·`camera` 행을 남기면, 뒤에 도는 지역 테스트가 `region`을 지울 때 외래키(zone→region)에 걸린다.
#10의 `ZoneRegisterTest`도 zone을 남겼지만, 실행 순서(region 테스트가 먼저) 덕에 우연히 통과하고 있었다.

## 해결
각 테스트가 끝난 뒤 `@AfterEach`로 camera → zone 순서로 지운다. `ZoneRegisterTest`에도 같은 정리를 넣었다(커밋 c3120f3).

## 재발 방지
DB를 공유하는 테스트는 자기가 만든 데이터를 스스로 지운다. 외래키 순서(자식 먼저)를 지킨다.
